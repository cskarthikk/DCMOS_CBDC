========================================================================================
PART 1: LIVE HARDWARE DEMO (WHEN BASYS 3 BOARD IS PLUGGED IN)
========================================================================================

STEP 1: FIND YOUR COM PORT
Command : [System.IO.Ports.SerialPort]::GetPortNames()
Purpose : Displays the COM port assigned to the Basys 3 board (e.g., COM3, COM4, COM5).

STEP 2: PROGRAM THE FPGA BOARD (LOAD BITSTREAM)
Command : powershell -ExecutionPolicy Bypass -File scripts\program_board.ps1
Purpose : Programs the Artix-7 chip with `bitstream\paper_array64.bit` via Vivado.
Check   : The 'DONE' LED on the Basys 3 board will light up GREEN when ready!

STEP 3: RUN LIVE END-TO-END CRYPTO KEY GENERATION
Command : powershell -ExecutionPolicy Bypass -File scripts\crypto_demo.ps1 -Port COM5
Purpose : Sends 8 live challenges to FPGA, captures 64 raw silicon bits, corrects noise
          via Dodis Code-Offset BCH(31,16,3), and displays live 256-bit AES master key.
Result  : 100% matched live key reconstruction directly from physical silicon!

----------------------------------------------------------------------------------------
*NOTE ON COM PORT "ACCESS DENIED":
If you get "Access denied", close Vivado Hardware Manager or unplug/replug the USB cable.
Remember to re-run STEP 2 after replugging because unplugging clears FPGA memory.
